# Altair8800Re

Remake of Altair 8800

制作一个Altair 8800的复制品

## 说明

* Chasis目录中为机箱钣金设计文件和3D打印的附件零件的文件，分别使用Fusion 360和SketchUp设计。

* PCB目录中为电路板设计文件，目前仅有基于David Hansel的Altair 8800 Due项目的简单设计（项目地址：[Arduino Altair 8800 Simulator - Hackster.io](https://www.hackster.io/david-hansel/arduino-altair-8800-simulator-3594a6)），适合单面覆铜板制作。未来会增加双面板的设计，更便于安装。
